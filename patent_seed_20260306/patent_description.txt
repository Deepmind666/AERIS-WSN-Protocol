说  明  书

发明名称：一种面向异构信道环境的无线传感器网络自适应分层路由方法及系统

技术领域

[0001] 本发明属于无线传感器网络（Wireless Sensor Network, WSN）路由协议技术领域，具体涉及一种面向异构信道环境的自适应分层路由方法及系统，适用于室内办公、室内工厂、室外城市和室外郊区等多种部署场景下的数据可靠传输。

背景技术

[0002] 无线传感器网络由大量分布式部署的微型传感器节点组成，通过自组织方式协同感知、采集和传输监测区域内的环境信息。随着物联网（IoT）技术的快速发展，WSN在工业监控、环境监测、智慧城市、精准农业等领域得到了广泛应用。在这些应用场景中，数据包传递率（Packet Delivery Ratio, PDR）是衡量网络可靠性的核心指标。

[0003] 现有的WSN路由协议主要包括以下几类：

[0004] （1）LEACH（Low-Energy Adaptive Clustering Hierarchy）协议：采用随机概率方式进行簇头选举，节点按照预设概率自主决定是否成为簇头。LEACH的主要局限在于：簇头选举完全依赖随机概率，未考虑节点剩余能量和链路质量；上行路由采用单跳直传至基站，缺乏路由质量保障机制；在不同信道衰减环境下性能波动大。

[0005] （2）PEGASIS（Power-Efficient Gathering in Sensor Information Systems）协议：采用链式拓扑结构，所有节点形成一条贯穿全网的链路，数据沿链路逐跳传递至链头再上传基站。PEGASIS的主要局限在于：链路跳数过多（实测平均达31跳以上），导致端到端延迟极高；链式结构对节点失效敏感，单点故障可能导致链路断裂；在大规模网络中链路维护开销显著增大。

[0006] （3）HEED（Hybrid Energy-Efficient Distributed clustering）协议：以节点剩余能量为主要参数、节点度数为辅助参数进行簇头选举。HEED的主要局限在于：评分维度仅包含能量和度数两个参数，忽视了实时链路质量和节点到基站距离等关键因素；在多种信道环境下适应性不足。

[0007] （4）TEEN（Threshold-sensitive Energy Efficient sensor Network）协议：采用基于阈值的事件驱动数据报告机制，仅在感知值超过设定阈值时才发送数据。TEEN的主要局限在于：阈值设置依赖于先验知识，在不同环境下难以统一配置；基于阈值抑制传输的机制导致PDR度量不公平，不同协议间难以进行公平比较。

[0008] 上述现有协议存在一个共同问题：大多数研究仅在单一、理想化的信道传播模型下进行评估，缺乏对异构信道环境（如室内办公的低衰减环境与室外城市的严重多径衰落环境）的系统性适应能力。当部署环境发生变化时，协议参数需要重新调优，缺乏跨环境的统一解决方案。

发明内容

[0009] 针对现有WSN路由协议在异构信道环境下数据包传递率低、跨环境适应性差的技术问题，本发明提供一种面向异构信道环境的无线传感器网络自适应分层路由方法及系统。

[0010] 本发明解决上述技术问题所采用的技术方案如下：

[0011] 一种面向异构信道环境的无线传感器网络自适应分层路由方法，包括以下步骤：

[0012] S1、簇头选举步骤：在每个通信轮次中，对网络中所有存活的传感器节点执行多维评分。评分函数综合考虑以下四个维度：（a）节点剩余能量占初始能量的比例E_residual；（b）节点在邻居节点集中的几何中心性度量Centrality；（c）节点到基站路径的链路质量指标LinkQuality，采用信噪比或误包率作为代理指标；（d）节点到基站的欧氏距离Distance。簇头评分函数为：

CH_Score = w_E·E_residual + w_C·Centrality + w_L·LinkQuality + w_D·(-Distance)

评分最高的前若干节点当选为当轮簇头。该评分在O(1)时间复杂度内完成，无需迭代优化过程。

[0013] S2、簇关联步骤：非簇头节点根据与各簇头之间的距离和链路质量综合评估，加入最优簇头所辖的簇。

[0014] S3、上下文自适应切换（Context-Adaptive Switching, CAS）步骤：对每个簇计算六维特征向量，包括链路质量q̂、剩余能量ê、归一化距离d̂、簇半径r̂、节点密度ρ̂和负载公平性f̂。利用固定系数的多特征线性评分函数，分别计算三种簇内通信模式的得分：

m* = arg max_{m∈{direct, chain, two-hop}} (w_{1,m}·q̂_m + w_{2,m}·ê_m + w_{3,m}^T·[d̂_m, r̂_m, ρ̂_m, f̂_m] + b_m)

其中各模式的固定权重系数为：
- 直接传输模式（direct）：w_q=0.65, w_e=0.35, w_d=-0.25, w_r=-0.05, w_ρ=0.10, w_f=-0.05
- 链式传输模式（chain）：w_q=0.40, w_e=0.30, w_d=0.20, w_r=0.20, w_ρ=0.20, w_f=-0.05
- 两跳传输模式（two-hop）：w_q=0.25, w_e=0.20, w_d=0.50, w_r=0.15, w_ρ=0.05, w_f=-0.05

选择得分最高的模式作为该簇当轮的簇内通信方式。特征向量各分量采用动态归一化，在每轮根据当前网络状态实时计算特征值域并映射到[0,1]范围，无需预定义环境分类器。

[0015] S4、条件网关强化步骤：对簇头到基站的直接路由质量进行实时评估。当直接路由的数据包传递率低于自适应阈值时，启用网关节点作为后备中继。网关候选节点的评分函数为：

Score_i = α·Ê_i + β·Ĉ_i + γ·L̂_i + δ·D̂_i

其中，Ê_i为节点i的归一化剩余能量（[0,1]），Ĉ_i为节点在簇头集中的中心性排名（[0,1]），L̂_i为节点到本簇簇头的链路质量（[0,1]），D̂_i为节点到基站的归一化距离（[0,1]）。固定系数分别为：α=0.15, β=0.20, γ=0.35, δ=-0.60。选择评分最高的前K个候选节点（K典型取2-3）作为网关。当直接路由质量满足要求时，网关模块不激活，避免不必要的能量开销。

[0016] S5、骨架主干网构建步骤：在簇头与基站之间建立层次化的多跳转发骨架网络。按照簇头到基站的距离进行分层，每层选择链路质量最优的转发节点。骨架网络在每轮根据簇头位置和链路质量的变化进行动态更新，作为网关路由失效时的第二级后备路径。

[0017] S6、级联失败转移步骤：数据上行传输时，按照以下优先级顺序进行级联尝试：

第一级：直接路由——簇头直接向基站发送数据；
第二级：网关路由——若直接路由失败且网关可用（I_g=1），通过网关节点转发；
第三级：骨架路由——若网关不可用或网关路由失败且骨架可用（I_s=1），通过骨架主干网多跳转发；
第四级：回退重传——若所有结构化路由均不可用，重新尝试直接传输。

级联转移的总成功概率为：

P_success = p_d + (1-p_d)·[I_g·p_g + (1-I_g)·I_s·p_s + (1-I_g)·(1-I_s)·p_b]

其中p_d、p_g、p_s、p_b分别为直接路由、网关路由、骨架路由和回退重传的成功概率。

[0018] 本发明还提供一种实现上述方法的无线传感器网络路由系统，包括：

（1）传感器节点模块：用于采集环境数据并计算簇内通信特征向量，内置上下文自适应切换单元，根据特征向量评分结果自动选择最优簇内通信模式；

（2）簇头节点模块：用于执行多维评分选举、簇内数据聚合以及上行路由决策，包含多维评分单元，综合能量、中心性、链路质量和距离四个维度进行评分；

（3）网关节点模块：用于在直接路由质量不足时提供后备中继服务，包含条件激活单元，根据实时链路质量评估结果决定是否启用网关转发功能；

（4）骨架主干网络模块：用于提供簇头到基站之间的层次化多跳转发路径，作为网关路由失效时的第二级后备；

（5）基站模块：用于接收各簇头上传的聚合数据，并维护全网拓扑信息和链路质量统计信息。

[0019] 上述传感器节点模块、簇头节点模块和网关节点模块均为软件功能模块，部署于具备IEEE 802.15.4无线通信能力的物联网传感器硬件节点上。同一物理节点在不同通信轮次中可分别承担传感器节点、簇头节点或网关节点的角色。

[0020] 本发明还提供一种计算机可读存储介质，所述存储介质上存储有计算机程序，所述计算机程序被处理器执行时实现上述面向异构信道环境的无线传感器网络自适应分层路由方法。

[0021] 与现有技术相比，本发明具有以下有益效果：

[0022] （1）数据包传递率显著提升：在100节点标准测试中（4种环境，每环境30个随机种子），本发明方法在所有4种环境中均排名第1。在100-1000节点大规模测试中（每个环境-节点-协议单元3200个样本，含显式MAC碰撞和多跳中继建模），本发明方法在24个测试单元中的18个排名第1。

[0023] （2）传输跳数大幅降低：本发明方法的平均传输跳数为1.97-1.99跳/包，而链式协议PEGASIS需31跳以上，实现约100倍的延迟优势。

[0024] （3）能量效率最优：本发明方法的总能耗为131.1J，低于LEACH的165.4J和PEGASIS的137.6J，在同等PDR水平下能量利用效率最高。

[0025] （4）跨环境无需重参数化：本发明方法采用统一的固定系数集，在室内办公（路径衰减指数n=2.0）、室内工厂（n=4.0）、室外城市（n=3.5）和室外郊区（n=2.5）四种异构信道环境下均有效，无需针对不同环境调整参数。

[0026] （5）确定性与可审计性：所有路由决策基于固定系数的线性评分函数，计算复杂度为O(1)每簇每轮次，相同输入必然产生相同输出，完全可审计和可复现。

具体实施方式

[0032] 下面结合附图和具体实施例对本发明作进一步详细描述。

[0033] 实施例1：室内工厂环境下的完整路由过程

[0034] 本实施例针对室内工厂环境（路径衰减指数n=4.0，高衰减、高干扰），部署100个传感器节点，1个基站位于监测区域中央，通信频率为IEEE 802.15.4标准的2.4GHz频段，发射功率为10dBm。

[0035] 步骤一（簇头选举，对应S1）：系统初始化后进入第一轮通信。对100个存活节点分别计算四维评分。例如，节点A的评分计算如下：E_residual=0.95（剩余能量95%），Centrality=0.72（位于节点密集区域），LinkQuality=0.58（工厂环境衰减较大），Distance归一化后为0.45。代入评分函数计算CH_Score，评分排名前5的节点当选为簇头。

[0036] 步骤二（簇关联，对应S2）：剩余95个非簇头节点分别计算到5个簇头的综合距离和链路质量指标，加入最优簇头，形成5个大小不等的簇。

[0037] 步骤三（CAS模式选择，对应S3）：以簇1为例，该簇包含22个节点，簇头为节点A。计算六维特征向量：q̂=0.58, ê=0.91, d̂=0.45, r̂=0.35, ρ̂=0.68, f̂=0.82。代入三模式评分函数：
- 直接传输得分：0.65×0.58 + 0.35×0.91 + (-0.25)×0.45 + (-0.05)×0.35 + 0.10×0.68 + (-0.05)×0.82 = 0.5515
- 链式传输得分：0.40×0.58 + 0.30×0.91 + 0.20×0.45 + 0.20×0.35 + 0.20×0.68 + (-0.05)×0.82 = 0.7600
- 两跳传输得分：0.25×0.58 + 0.20×0.91 + 0.50×0.45 + 0.15×0.35 + 0.05×0.68 + (-0.05)×0.82 = 0.5835

链式传输得分最高（0.7600），因此簇1在本轮次选择链式传输模式进行簇内数据收集。该选择反映了室内工厂环境中链路质量中等、节点密度较高的特点，链式模式能够利用多跳协作提高可靠性。

[0038] 步骤四（网关条件激活，对应S4）：簇头A评估到基站的直接路由质量。由于室内工厂环境衰减指数高（n=4.0），直接路由PDR仅为0.62，低于自适应阈值0.75。系统启用网关强化机制。对簇1附近的候选网关节点评分，节点B的网关评分为：Score_B = 0.15×0.88 + 0.20×0.65 + 0.35×0.79 + (-0.60)×0.32 = 0.3475。选择评分最高的前2个节点作为网关。

[0039] 步骤五（骨架主干网，对应S5）：系统同时构建簇头A到基站的骨架多跳路径，经由距离分层的中继节点形成两跳骨架路径，作为网关失效时的后备。

[0040] 步骤六（级联转移，对应S6）：簇头A尝试通过网关B转发聚合数据至基站。若网关路由成功，则数据传递完成。若网关路由也失败，系统自动切换至骨架路由进行多跳转发。

[0041] 在室内工厂环境的100节点测试中，本方法的PDR达到0.6031，显著高于PEGASIS的0.1928和HEED的0.2326，网关强化模块的消融实验显示其贡献了+2.25个百分点的PDR提升（Holm校正后统计显著）。

[0042] 实施例2：室外城市环境下的Gateway启用场景

[0043] 本实施例针对室外城市环境（路径衰减指数n=3.5，严重多径衰落），部署500个传感器节点，发射功率为10dBm。

[0044] 在室外城市环境中，由于建筑物遮挡和多径效应严重，基站方向的直接链路质量普遍较低。CAS模块在大多数簇中选择两跳传输模式（因w_d=0.50的距离权重主导），以减少单跳传输距离从而提高链路可靠性。

[0045] 网关条件激活在该环境下发挥关键作用：约72%的簇头触发了网关强化机制。消融实验表明，Gateway模块在室外城市环境贡献了+2.12个百分点的PDR提升，CAS模块贡献了+2.44个百分点（两者均通过Holm校正后显著性检验，p<0.005）。

[0046] 级联失败转移机制在该环境下的实际调用统计为：约68%的数据包通过直接路由成功传递，22%通过网关路由传递，8%通过骨架路由传递，2%通过回退重传传递。四级级联机制将整体PDR提升至0.1359（500节点），远高于LEACH的0.0413和PEGASIS的0.0542。

[0047] 实施例3：100至1000节点的可扩展性验证

[0048] 本实施例验证本发明方法在不同网络规模下的可扩展性。在四种环境中分别部署100、200、300、500、800和1000个节点，每个环境-节点-协议组合执行3200个样本的统计测试（含显式MAC碰撞和多跳中继建模）。

[0049] 测试结果表明：
（1）本方法在所有规模和环境组合中均保持可用的PDR水平，从100节点到1000节点的PDR下降幅度在可接受范围内（室内工厂：-0.05，下降8.3%；室外城市：-0.24，下降64%）；
（2）在24个环境-规模测试单元中，本方法在18个单元排名第1，仅在室内办公环境的高规模（500-1000节点）下被PEGASIS超越；
（3）所有协议间差异均通过Holm校正后统计显著性检验（α=0.05），排除了随机波动的可能性；
（4）传输跳数随规模增大保持稳定（1.97-1.99跳），未出现链式协议的跳数爆炸问题。

[0050] 此外，三级发射功率敏感性测试（5/10/15 dBm，每单元1000个样本）表明，PDR对功率的响应是环境依赖且非单调的。例如在室内工厂500节点场景下，10dBm功率设置优于5dBm和15dBm，原因是高功率导致干扰域扩展从而增加MAC碰撞。本方法在所有功率设置下均保持相对最优或次优的PDR排名，体现了参数鲁棒性。
