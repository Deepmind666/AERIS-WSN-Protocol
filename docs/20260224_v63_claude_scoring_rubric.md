# AERIS v63 审稿评分量表（Scoring Rubric）

> **使用方式**：本文件由主提示词引用，审稿 Claude 在打分阶段必须严格遵循本量表。

---

## 1. 评分维度与权重（满分 100）

| 维度 | 权重 | 判定要点 |
|------|-----:|----------|
| 数据一致性与可复现性 | 30 | 表格数值与源 CSV/JSON 完全一致；PDR 口径统一；数据可追溯至权威文件 |
| 方法与逻辑严谨性 | 20 | 论证闭环；legacy/primary 边界清晰；无自相矛盾；因果链完整 |
| 图表质量与图文一致 | 15 | 图-文-公式语义对齐；图版本统一（s62）；图可读性合格；workflow 与 Section 3 匹配 |
| 统计与显著性表达 | 10 | p 值/效应量（Hedges' g）解释正确；Holm 校正门控语句准确；置信区间表述规范 |

| 投稿合规性（模板/格式） | 5 | MDPI 模板格式正确；交叉引用无断裂；图表编号连续；caption 规范 |

---

## 2. P 级问题定义

### P0（阻塞投稿）
任何一项即触发"至少 Major"：
- 表格数值与源 CSV/JSON 不一致（任何一个数值）
- `.tex` 被引键在 `bibliography.bib` 中缺失
- 被引键 DOI 不可解析（基于 `v62_cited_doi_validation.csv`）
- 结论越界：跨口径混用（legacy 数据支撑 primary 结论）
- 关键图文冲突导致核心结论不可验证

### P1（应修复）
不阻塞编译但显著影响审稿判断：
- 图版本不一致（混用 s60/s59 等旧版本）
- 摘要 legacy/primary 边界表述模糊
- 统计量解释不准确（如 Hedges' g 阈值误用）
- 术语前后不一致
- Table caption 缺少必要限定语

### P2（可选优化）
不影响投稿门槛：
- 排版微调（间距、字体一致性）
- 非关键表述润色
- 补充性说明建议（不改变结论）

---

## 3. 评级阈值

| 条件 | 评级 |
|------|------|
| 总分 ≥ 85 且 P0 = 0 且 P1 ≤ 2 | **Accept（可投稿）** |
| 总分 70–84 或 P1 > 2（但 P0 = 0） | **Minor Revision** |
| 总分 < 70 或 P1 > 5（但 P0 = 0） | **Major Revision** |
| 任意 P0 ≥ 1 | 至少 **Major**，若 P0 ≥ 3 则 **Reject** |

---

## 4. 门控一致性规则（硬约束）

1. **有 P0 不得给 Accept**——违反此规则则整份报告判定逻辑错误
2. **给 Reject/Major 时必须附最小修复路径**：
   - 24h 可完成项（紧急阻塞修复）
   - 72h 可完成项（完整收口）
3. **所有问题必须给到 `文件路径:行号` 证据**——未绑定证据的问题不计分
4. **未绑定证据的断言出现 ≥ 1 条**——整份报告降级为"不合格"

---

## 5. 边界纪律（硬约束）

- 不允许建议新增实验（除非明确发现 P0 且无法文本修复）
- 不允许改数据口径（PDR 口径锁定为 `pdr_expected`）
- 不允许改结论范围超出 v63 事实
- 不允许建议修改 `src/` 代码

---

## 6. 打分流程（执行顺序）

1. 完成数据核对（Table 1/3/4 vs 源 CSV/JSON）
2. 完成 cite-bib 与 DOI 核对
3. 完成 workflow 与 Section 3 对齐核对
4. 完成图版本（s62）核对
5. 完成摘要边界核对
6. 归类所有问题为 P0/P1/P2
7. 按 7 个维度逐项打分并汇总总分
8. 应用评级阈值，输出门控结论
9. 若非 Accept，输出最小修复路径
